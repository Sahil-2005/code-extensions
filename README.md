# 🧩 Code Extensions

A collection of custom VS Code extensions built to supercharge developer productivity.

---

## 📦 Extensions

| Extension | Description | Marketplace | Status |
|-----------|-------------|-------------|--------|
| [**PromptTune**](./promptTune/) | Instantly rewrite and optimize AI prompts using Gemini — select text, run the command, get a production-ready prompt. | [![Install](https://img.shields.io/badge/Install-Marketplace-blue?logo=visualstudiocode)](https://marketplace.visualstudio.com/items?itemName=sahil-2005.prompttune) | ✅ Published |

---

## 🚀 Getting Started

Each extension lives in its own folder with a dedicated README. Navigate into any extension directory for setup instructions, features, and usage details.

```bash
cd promptTune
npm install
npm run compile
```

---

## 🛠️ Tech Stack

- **Environment:** Node.js, TypeScript
- **Platform:** VS Code Extension API
- **Bundler:** Webpack
